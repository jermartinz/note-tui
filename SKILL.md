## Workflow

1. Inspect the project before modifying anything.
2. Explain the relevant architecture briefly.
3. Implement the smallest useful change.
4. Clearly identify any new concept introduced.
5. Prefer simple code over clever abstractions.
6. After implementing the change, explain:
   - what changed
   - why it works
   - which files matter
   - what the user should understand from the implementation

Before completing:

- Run tests or relevant checks.

- Ensure there are no unnecessary dependencies.
